# TASK 07.6.1 — Final Map Tile Verification & Cleanup (branch `feature/ui-foundation-map-stability`)

- **Root Cause of Watermark:** Visual inspection of map screenshots from Task 07.6 revealed CARTO had introduced an unauthenticated diagonal watermark banner `"API KEY REQUIRED carto.com/basemaps/apikey"` across their raster basemaps.
- **Investigation & Benchmark:** Benchmarked multiple public endpoints. Upstream `tile.openstreetmap.org` is blocked by VN ISPs (WinError 10061). CARTO requires an API key to remove watermark. OpenStreetMap Humanitarian (HOT) hosted by OpenStreetMap France (`https://{s}.tile.openstreetmap.fr/hot/{z}/{x}/{y}.png`) and OSM-FR (`https://{s}.tile.openstreetmap.fr/osmfr/{z}/{x}/{y}.png`) are 100% reachable (HTTP 200, ~165ms), have full CORS (`*`), support native Vietnamese UTF-8 labels, require 0 API keys, and have ZERO watermark.
- **Tile Implementation:** Replaced CARTO Voyager with OpenStreetMap Humanitarian (HOT) as primary tile source, with OSM-FR as fallback in `apps/mobile/lib/features/map/presentation/map_screen.dart`.
- **Attribution:** Updated attribution widget to `"OpenStreetMap contributors"` and `"Tiles: Humanitarian OpenStreetMap Team / OSM France"`.
- **Documentation:** Updated `docs/architecture/decisions/ADR-006-map-tile-provider.md` and `docs/architecture/ui-architecture.md`.
- **Automated Tests:** Flutter 82 passed, Backend 62 passed, AI 87 passed (+ 2 skipped). Total: 231 passed. Builds & analyze clean.
